## Server Requirements

| Requirement | Minimum | Notes |
|---|---|---|
| PHP | 8.3 | With extensions: pdo_mysql, mbstring, openssl, tokenizer, xml, bcmath, fileinfo, zip |
| MySQL | 8.0 | Primary database |
| Node.js | 18 | Required for Astro frontend build only |
| Composer | 2.x | PHP dependency manager |
| NPM | 9+ | Node package manager |
| Web server | Nginx or Apache | PHP-FPM recommended |
| SSL | Required | HTTPS mandatory for payment webhooks |
| Cron | Required | For Laravel scheduler (`php artisan schedule:run`) |
| Queue worker | Required | Persistent `php artisan queue:work` process |

## Environment Variables

All configuration is provided through `.env`. Never commit the `.env` file — use `.env.example` as the template.

### Application

| Key | Description | Example |
|---|---|---|
| `APP_NAME` | Application name | `Okina Business System` |
| `APP_ENV` | Environment (`production`, `local`) | `production` |
| `APP_KEY` | Laravel encryption key | Generated by `php artisan key:generate` |
| `APP_DEBUG` | Enable debug mode (`false` in production) | `false` |
| `APP_URL` | Public application URL | `https://admin.okinacraft.com` |

### Database

| Key | Description |
|---|---|
| `DB_CONNECTION` | `mysql` |
| `DB_HOST` | MySQL host |
| `DB_PORT` | MySQL port (default `3306`) |
| `DB_DATABASE` | Database name |
| `DB_USERNAME` | Database username |
| `DB_PASSWORD` | Database password |

### Queue

| Key | Description |
|---|---|
| `QUEUE_CONNECTION` | `database` (production); `sync` (development only) |

### Cache and Session

| Key | Description |
|---|---|
| `CACHE_DRIVER` | `file` or `redis` |
| `SESSION_DRIVER` | `file` or `cookie` |

### File Storage

| Key | Description |
|---|---|
| `FILESYSTEM_DISK` | `local` |
| `PRIVATE_DISK` | `private` (maps to `storage/app/private/`) |

### Payment — Cashfree

## Deployment Summary

For the full step-by-step procedure, see [DEPLOYMENT-CHECKLIST.md](./DEPLOYMENT-CHECKLIST.md).

The high-level sequence is:

```
1. Enable maintenance mode        php artisan down
2. Pull latest code               git pull origin main
3. Install dependencies           composer install --no-dev --optimize-autoloader
4. Run database migrations        php artisan migrate --force
5. Clear and rebuild caches       php artisan optimize
6. Restart queue workers          (reload supervisor or restart process)
7. Build Astro frontend           npm ci && npm run build
8. Disable maintenance mode       php artisan up
9. Run health checks              php artisan about, check logs
```

## First-Time Setup

```powershell
# Backend
cd apps/backend
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link

# Frontend
cd apps/frontend
npm ci
npm run build
```

## Queue Worker (Production)

The queue worker must be a persistent, supervised process in production. Use Supervisor or a similar process manager:

```ini
[program:okina-queue-worker]
command=php /path/to/apps/backend/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
user=www-data
redirect_stderr=true
```

---

## Scheduler (Production)

Add to the web server user's crontab:

```
* * * * * cd /path/to/apps/backend && php artisan schedule:run >> /dev/null 2>&1
```

The scheduler handles:
- Daily `audit:prune`
- Daily `system:backup` (if configured)
- Notification retry sweeps
