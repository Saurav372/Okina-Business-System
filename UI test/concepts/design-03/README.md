# Design 03 — Depop-inspired marketplace storefront

An isolated, static UI prototype for Okina. It borrows the useful marketplace structure—strong search, dense product discovery, simple category navigation, and direct product cards—without copying Depop branding or assets.

## Pages

- `index.html` — audience-led homepage
- `shop.html` — searchable and filterable catalogue
- `product.html` — product, materials, colours, sizes, and proof promise
- `customize.html` — four-step artwork and quantity builder
- `cart.html` — saved customization summary
- `checkout.html` — validated delivery and payment handoff
- `confirmation.html` — order success and next steps
- `quote.html` — 25+ piece quotation confirmation with no payment taken
- `account.html` — orders, retry-payment recovery, and repeat order
- `track.html` — proof approval and fulfilment timeline

## Run locally

Serve this folder with any static web server, then open `index.html`. No build step or production-project changes are required.

All imagery is stored in `assets/`; interactions use local browser storage only.
