# Design 01 — Living Catalog

A static storefront experiment inspired by the browsing patterns found in
Mobbin's web storefront collection: search first, clear promotional story,
purpose-led discovery, visible products, and simple category navigation.

The visual design, copy, colours, layout, and product treatment are original to
Okina Craft. This concept does not import code from the Astro storefront.

Open `index.html` through a local web server to review the concept.
