# Design 04 — PrintMine-inspired Okina storefront

An isolated static prototype that translates the useful commerce patterns from PrintMine’s live storefront and custom T-shirt product into Okina’s identity and requirements. It does not copy PrintMine branding, copy, or product assets.

## Pages

- `index.html` — campaign storefront, categories, hot sellers, trust, process, reviews
- `shop.html` — searchable/filterable collection
- `create.html` — inline garment configuration, size planning, artwork, quantity pricing
- `cart.html` — retained configuration and recovery
- `checkout.html` — delivery, payment choice, validation, proof terms
- `confirmation.html` — paid order success and proof handoff
- `quote.html` — 25+ piece quotation route with no payment taken
- `account.html` — order history, pending-payment retry, repeat order
- `track.html` — proof approval and production timeline

Run this directory with any static server. All state is stored only in the browser for this prototype.
