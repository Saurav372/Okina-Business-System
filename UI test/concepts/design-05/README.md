# Okina Craft — Design 05

An isolated storefront prototype inspired by the clean retail structure of Destiny Clothing and rebuilt around Okina's proof-first custom apparel workflow.

## Pages

- `index.html` — storefront homepage
- `shop.html` — searchable and filterable product catalogue
- `create.html` — product configuration, quantities, artwork, delivery check
- `cart.html` — configured bag with remove and restore states
- `checkout.html` — delivery and payment form with validation
- `confirmation.html` — successful small-order confirmation
- `quote.html` — 25+ piece quotation confirmation
- `account.html` — orders, payment recovery, and proof status
- `track.html` — production timeline and proof approval

## Run

Serve this folder with any static web server. The prototype stores only temporary demo configuration in browser storage.

The production project is not connected to or changed by this concept.
