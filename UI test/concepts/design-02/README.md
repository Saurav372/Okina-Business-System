# Design 02 — Campaign Motion

Three linked storefront screens:

- `index.html`: high-energy campaign homepage using the structural lessons of
  Adidas' image-led landing page.
- `shop.html`: calmer, product-first collection browsing using the structural
  lessons of Lululemon's storefront.
- `product.html`: spacious product configuration, visible proof reassurance,
  and a floating selection card.

The implementation does not copy either brand's identity, assets, layout, or
trade dress. It uses original Okina copy, controls, colors, and generated hero
photography.

## Generated campaign asset

Built-in ImageGen created `assets/okina-campaign-hero.png` as an original,
ultra-wide editorial photograph of young Indian creators wearing premium black,
white, and red apparel in an urban Bengaluru studio. The prompt excluded brand
logos, trademarks, text, watermarks, and recognizable reference-brand styling.
